How it works

Z-app Video Scheduler is a personal publishing tool. It is used only by its developer, for the developer's own channels. There is no public sign-up.

Publishing flow

  1. Write the script. Each episode is a short script with scenes, narration and on-screen text.
  2. Render. An automated job renders the script into a vertical 9:16 video with animation, captions and a voice-over.
  3. Publish. The same job uploads the finished video with its title and caption to YouTube (YouTube Data API), Instagram (Instagram Graph API) and TikTok (TikTok Content Posting API).
  4. Schedule. Jobs run automatically on a weekly schedule, at 6am UK time.

TikTok integration

The tool uses TikTok Login Kit so the account owner can authorise it once, and the Content Posting API to publish videos to that same account. It requests only these scopes:

  • user.info.basic: to show which TikTok account is connected.
  • video.publish: to post the creator's own videos to their own account.

Before each post, the creator chooses the privacy level, whether comments, duets and stitches are allowed, and any content disclosure, following TikTok's posting guidelines. Videos created with AI tools are labelled as AI-generated.

Data

The tool does not collect data from viewers or any other users. Access tokens are stored as encrypted secrets and used only to publish. See the Privacy Policy for details.
